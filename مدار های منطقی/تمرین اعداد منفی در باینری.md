[[اعداد منفی در باینری]]

---

برای اینکه دستت راه بیفته، اینم ۶ تا تمرین دیگه. خودت سعی کن با همون روشی که گفتی حلشون کنی (سریع و ساده):

| عدد مورد نظر (ده‌دهی) | جواب در سیستم ۴ بیتی |
| :-------------------- | :------------------- |
| ۵                     | 0101                 |
| ۷-                    | 1001                 |
| ۸-                    | 1000 (عجیبه خودش شد) |
| ۲                     | 0010                 |
| ۴-                    | 1100                 |
| ۱-                    | 1111                 |

یادت باشه:
*   اگه عدد مثبته که مستقیم بنویسش (فقط حواست به ۴ بیت بودن باشه).
*   اگه منفیه، از همون روش "وارونه کن و ۱ واحد اضافه کن" برو.

بزن بریم! جواباشون رو داری یا حلشون کنی؟
