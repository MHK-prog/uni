توی برنامه‌نویسی با جاوااسکریپت، تابعی داری که ورودی می‌گیره و خروجی `true` یا `false` میده؟ (بهش می‌گن Predicate یا تابع شرطی).

دقیقاً **$P(x)$ همون تابع شرطی (Boolean Function) هست!**

حرف **$P$** اول کلمه‌ی **Predicate** (محمول / ویژگی / گزاره‌نما) هست و $x$ هم ورودی یا متغیره.

---

### مثال خیلی ساده:

فرض کن $P(x)$ این باشه: **«$x$ زوج است»**  
توی JS این شکلی می‌نویسیش:
```javascript
const P = (x) => x % 2 === 0;
```

حالا به ازای ورودی‌های مختلف:
* اگه بذاری ۴: $P(4)$ میشه **True** (درست).
* اگه بذاری ۵: $P(5)$ میشه **False** (غلط).

به خودِ «$x$ زوج است» تا وقتی مقداری به $x$ ندادی، نمی‌تونی بگی درسته یا غلط. به این فرمول یا ویژگیِ باز می‌گن **$P(x)$**.

---

### حالا چرا میاد بغل سورها؟

ریاضی‌دان‌ها برای اینکه هر دفعه جمله‌های طولانی مثل «$x$ زوج است» یا «$x$ دانشجو است» رو ننویسن، همه‌چیز رو خلاصه می‌کنن با $P(x)$ یا $Q(x)$.

مثلاً می‌نویسن:
$$\forall x \, P(x)$$

یعنی:
> «به ازای هر عددی که به تابع $P$ بدی، خروجیش True میشه.»  
(توی مثال بالا یعنی: **همه‌ی اعداد زوج هستند** — که البته غلطه).

یا می‌نویسن:
$$\exists x \, P(x)$$

یعنی:
> «حداقل یه عدد $x$ پیدا میشه که اگر به تابع بدی، خروجیش True بشه.»  
(یعنی: **حداقل یه عدد زوج وجود داره** — که درسته، مثلاً ۲).

---

### اگه دو تا متغیر باشه: $P(x, y)$
دقیقاً مثل تابعیه که دو تا ورودی می‌گیره:
```javascript
const P = (x, y) => x + y === 0;
```
اینجا $P(x, y)$ یعنی رابطه‌ی بین $x$ و $y$ که برابر صفر بشه.

### خلاصه:
ووو $P(x)$ یعنی **یک ویژگی، صفت، یا معادله درباره‌ی $x$** که وقتی مقدار عددی یا شیء واقعی به جاش بذاری، معلوم میشه درسته یا غلط.
