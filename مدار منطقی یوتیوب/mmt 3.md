# 📝 جزوه مرور سریع: عملیات محاسباتی در سیستم دودویی (Binary Arithmetic)

---

## ۱. جمع دودویی (Binary Addition)

### قوانین جمع دو بیت:
* $0 + 0 = 0$
* $0 + 1 = 1$
* $1 + 1 = 10_2$ (حاصل $0$ و رقم نقلی Carry = $1$)
* $1 + 1 + 1 = 11_2$ (حاصل $1$ و رقم نقلی Carry = $1$)

### مثال:
```text
  1 1 1 1 1      <-- Carry (رقم نقلی)
    1 1 1 1 0 1  = (61)₁₀
+     1 0 1 1 1  = (23)₁₀
________________
  1 0 1 0 1 0 0  = (84)₁₀   ✓
```

---

## ۲. تفریق دودویی (Binary Subtraction)

### قوانین تفریق دو بیت:
* $0 - 0 = 0$
* $1 - 0 = 1$
* $1 - 1 = 0$
* $0 - 1 = 1$ (با یک قرض / Borrow از ستون چپ‌تر؛ وقتی قرض می‌گیریم، ارزش آن در ستون فعلی معادل $2$ در مبنای ۱۰ یا همان $10_2$ است: $2 - 1 = 1$).

### مثال:
```text
  0 1 2 0 2      <-- ارقام بعد از قرض گرفتن (Borrow)
  1 0 0 1 1 0 1  = (77)₁₀
-     1 0 1 1 1  = (23)₁₀
________________
  0 1 1 0 1 1 0  = (54)₁₀   ✓
```

> **نکته:** رقم اول از راست $1 - 1 = 0$. در رقم دوم $0 - 1$ داریم؛ از بیت سوم قرض می‌گیریم که خودش $1$ است و می‌شود $0$. بیت دوم می‌شود $2$ و $2 - 1 = 1$. در ادامه هم قرض گرفتن‌های پیاپی روی صفرها، آن‌ها را به $1$ تبدیل می‌کند.

---

## ۳. ضرب دودویی (Binary Multiplication)

ضرب دقیقاً مثل ضرب دبستانی است، با این تفاوت که جدول‌ضرب بسیار ساده است:
* اگر رقم ضرب‌کننده **۱** باشد $\to$ خود عدد را کپی می‌کنیم.
* اگر رقم ضرب‌کننده **۰** باشد $\to$ ردیف صفر قرار می‌دهیم.
* در هر ردیف، یک پله به چپ شیفت می‌دهیم و در انتها همه را با جمع باینری جمع می‌زنیم.

### مثال:
```text
        1 0 1 1 1      = (23)₁₀
     ×    1 0 1 0      = (10)₁₀
_________________
        0 0 0 0 0      (ضرب در 0)
+     1 0 1 1 1 ·      (ضرب در 1)
+   0 0 0 0 0 · ·      (ضرب در 0)
+ 1 0 1 1 1 · · ·      (ضرب در 1)
_________________
  1 1 1 0 0 1 1 0      = (230)₁₀   ✓
```

## ۴. تقسیم دودویی (Binary Division)

تقسیم طولانی (Long Division) در باینری فوق‌العاده ساده است: مقسوم‌علیه یا در عدد جا می‌شود (خارج‌قسمت **۱**) یا جا نمی‌شود (خارج‌قسمت **۰**).

### مثال: $(1110111)_2 \div (1001)_2$
معادل دسیمال: $119 \div 9 = 13$ با باقی‌مانده $2$

```text
       1 1 0 1   <-- خارج‌قسمت (Quotient) = (13)₁₀
     ___________
1001 ) 1 1 1 0 1 1 1   = (119)₁₀
     - 1 0 0 1
       _______
         1 0 1 1
       - 1 0 0 1
         _______
             0 1 0 1   (1001 در 010 جا نمی‌شود -> قرار دادن 0 در خارج‌قسمت)
             1 0 1 1
           - 1 0 0 1
             _______
                 0 1 0 <-- باقی‌مانده (Remainder) = (2)₁₀   ✓
```
