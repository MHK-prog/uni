فرض کنید x یک عدد حقیقی دلخواه باشد در این صورت عدد صحیح و منحصربه فرد n چنان وجود دارد که:
$n <= x$
n را جز صحیح x گویند و با [x]
همواره داریم :

$$
[x] = n \\ \\
[x] \le x \le [x] + 1 \\ \\
x-1 < [x] \le x \\ \\
x = [x] + P ; 0 \le P < 1 \\ \\
[x+m] = [x] +m \, (m \in \mathbb{Z})
$$

مثال و تمرین:
مطلوب است حل معدلات و نمعادلات زیر:
1. $[x] = 3$
2. $[\frac{x-1}{2}] = 1$ 
3. $2[2x+1] = 3$ 
4. $[x] \ge 3$ 
5. $[x] < 5$ 
6. $[2x+1] = 5$ 
7. $[x+[x]] = 4$
