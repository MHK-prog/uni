## کد (Code) — توضیح کامل

### چی هست؟
کد همون **نوشته‌های اصلی برنامه** به زبان کامپیوتره که با رعایت قواعد دقیق (سینتکس) یک زبان برنامه‌نویسی خاص نوشته می‌شه. مثل ++C، پایتون، جاوا و ...

### کاراکترهاش رو بگو:
- **دقیق بهحالتی** — کوچکترین ایراد تایپی یا کولن گمشده باعث خطا می‌شه.
- **وابسته به زبان** — کدی که برای ++C نوشته می‌شه، مستقیم در پایتون اجرا نمی‌شه.
- **مستقیم توسط کامپیوتر اجرا می‌شه** — بعد کامپایلشدن، تبدیل به زبان ماشین می‌شه از طریق **کامپایلر**.
- **داخل محیط IDE نوشته می‌شه** — مثل VS Code یا توربو سی.

### مثال واقعی (در ++C):
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;          // مقدار ام
    cout << "عدد: " << a << endl;   // چاپ
    return 0;
}
```
> اینجا هر نیشانگ (مثل `;` یا `{`) ضروریه. اگر یه دونه شون کم شه، کد اجرا نمی‌شه.

### جالبی بزرگ:
مهم، کد **بدون** فکر به منطق ریاضی نوشته نمی‌شه؛ اول الگوریتم باید روشن باشه، بعد کدنویسی.

## شبه‌کد (Pseudo-code) — توضیح کامل

### چی هست؟
شبه‌کد یک **زبان میانی بین انسان و کامپیوتر**ه. نه فارسی خالصه و نه سینتکس واقعی یک زبان. هدفش اینه که منطق الگوریتم رو بدون درگیرشدن با نحو، ساده و خوانا بیان کنه.

### کاراکترهاش:
- **قابل فهم برای انسان** — همونطور که کامپیوترمونه بهش نگاه می‌کنیم راحت می‌فهمیم چی می‌خواهیم.
- **مستقل از زبان برنامه‌نویسی** — سینتکس مشخص نداره؛ قواعد استاندارد خاصی نداره.
- **اجرا نمی‌شه** — نمیشه مستقیم در یک مترجم یا کامپایلر اجرا کرد؛ فقط برای فکر و طراحی کار می‌بری.
- **گام بزرگی برای کدنویسی** — قبل از نوشتن کد واقعی، منطق رو در شبه‌کد ثبت می‌کنیم.

### مثال شبه‌کد برای همون برنامه قبلی:
```
شروع
  قرائت عدد ورودی (در ا = 5)
  نمایش: "عدد: " + ا
پایان
```
> ببین چقدر ساده و خوانا است؛ بدون `;` بدون `{}` بدون نیشانگ پیچیده.

---

## فرق اساسی این دو در یه بورد: 

| موضوع | کد (Code) | شبه‌کد (Pseudo-code) |
|---|---|---|
| قواعد | سخت و دقیق به زبان خاص | ساده و آزاد |
| خوانای برای انسان | متوسط | بسیار بالا |
| اجرا توسط کامپیوتر | مستقیم (بعد کامپایل) | اصلا اجرا نمی‌شه |
| استفاده در محیط | IDE (مثل VS Code) | على برگه یا ویرایشگر ساده |
| هدف | اجرا برنامه واقعی | طراحی منطق الگوریتم |

---

### جمع بندی:
> **اول** در شبه‌کد فکر و طراحی می‌کنیم (ام گام منطقی)، **بعد** همون منطق رو به کد واقعی یک زبان می‌بریم (ام گام فنی) و اولویت اجراش می‌کنیم.
