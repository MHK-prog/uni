# 02 - انتگرال نامعین

> ⬅️ قبلی: [[01-Introduction|مفهوم انتگرال]] | بعدی: [[03-Definite-Integrals|انتگرال معین]] | 🏠 [[00-Index|فهرست اصلی]]

## پادمشتق یعنی چی؟

انتگرال نامعین در واقع **برعکس مشتق‌گیری** است. بهش می‌گن «پادمشتق»:

$$F'(x)=f(x) \quad\Longrightarrow\quad \int f(x)\,dx = F(x)+C$$

اون $C$ ثابت دلخواهه، چون مشتق هر ثابتی صفره! مثلاً مشتق $x^2$ و $x^2+100$ هر دو $2x$ است.

## جدول انتگرال‌های اصلی 📋

| تابع | انتگرال |
|---|---|
| $x^n\ (n\ne -1)$ | $\dfrac{x^{n+1}}{n+1}+C$ |
| $\dfrac{1}{x}$ | $\ln\lvert x\rvert + C$ |
| $e^x$ | $e^x + C$ |
| $a^x$ | $\dfrac{a^x}{\ln a}+C$ |
| $\sin x$ | $-\cos x + C$ |
| $\cos x$ | $\sin x + C$ |
| $\sec^2 x$ | $\tan x + C$ |
| $\dfrac{1}{1+x^2}$ | $\arctan x + C$ |
| $\dfrac{1}{\sqrt{1-x^2}}$ | $\arcsin x + C$ |

## خواص جبری

1. $\displaystyle\int k\,f(x)\,dx = k\int f(x)\,dx$
2. $\displaystyle\int \big[f(x)\pm g(x)\big]dx = \int f(x)\,dx \pm \int g(x)\,dx$

## مثال‌های حل‌شده

**مثال ۱:**
$$\int (3x^2 + 2x - 5)\,dx = x^3 + x^2 - 5x + C$$

**مثال ۲:**
$$\int \frac{1}{x^2}\,dx = \int x^{-2}dx = -x^{-1}+C = -\frac{1}{x}+C$$

**مثال ۳:**
$$\int \left(e^x + \cos x\right)dx = e^x + \sin x + C$$

## هشدار ⚠️

- ثابت $C$ رو یادت نره! خیلی از دبیرها/استادها به خاطر جا انداختنش نمره کم می‌کنن.
- جواب رو می‌شه با **مشتق گرفتن** چک کرد؛ همیشه این کار رو بکن.
