## ۱. جابه‌جایی و مدیریت مسیرها (Navigation)

### `cd\` یا `cd/`
- بازگشت مستقیم به ریشه (Root) درایو فعلی.
```cmd
C:\Users\MHK1257> cd\
C:\>
```

### `cd ..`
- برگشت به پوشه والد (یک مرحله عقب‌تر).
```cmd
C:\Windows> cd..
C:\>
```

### `cd <FolderName>`
- ورود به پوشه مشخص‌شده.
```cmd
C:\> cd windows
C:\Windows>
```

### `cd` (بدون پارامتر)
- نمایش مسیر فعلی که در آن قرار دارید.
```cmd
D:\Test\Test1> cd
D:\Test\Test1
```

> [!WARNING] نکته تله امتحانی:
> دستور `cd` فقط برای **پوشه‌ها (Directories)** است! اگر روی فایل اجرا شود، با خطای زیر مواجه می‌شوید:
> ```cmd
> D:\Test\Test1> cd B.txt
> The system cannot find the path specified.
> ```

## ۲. تغییر درایو

برای جابه‌جا شدن بین درایوها، نباید از دستور `cd` استفاده کنید و نوشتن نام خالی درایو هم غلط است. فقط **نام درایو + دونقطه (`:`)**:

- ❌ اشتباه: `d`
- ✔️ درست: `d:`
```cmd
C:\> d:
D:\>
```

## ۳. مشاهده محتویات دایرکتوری (`dir`)

### `dir`
- لیست فایل‌ها، پوشه‌ها، حجم‌ها، تاریخ آخرین تغییرات و فضای خالی درایو را نشان می‌دهد.

### `dir /p`
- **نمایش صفحه‌به‌صفحه (Page by Page):** وقتی محتویات یک پوشه زیاد باشد (مثل پوشه Windows)، صفحه را نگه می‌دارد و با زدن کلیدی (Press any key to continue) صفحه بعد را نشان می‌دهد تا خروجی اسکرول نشود و از دست نرود.

## ۴. ساخت، کپی و حذف فایل‌ها و پوشه‌ها

### `md <FolderName>` (مخفف Make Directory)
- ساخت یک پوشه جدید (معادل `mkdir`).
```cmd
D:\> md Test
```

### `copy <Source> <Destination>`
- کپی کردن فایل از مبدأ به مقصد.
```cmd
D:\Test\Test1> copy B.txt D:\Test
        1 file(s) copied.
```

### `del <FileName>` (مخفف Delete)
- حذف فایل مشخص‌شده.
```cmd
D:\Test\Test1> del B.txt
```

## ۵. دستورات سیستمی و اطلاعاتی

### `ver`
- نمایش نسخه دقیق سیستم‌عامل ویندوز (Version).
```cmd
D:\> ver
Microsoft Windows [Version 10.0.19045.6466]
```

### `date`
- نمایش تاریخ فعلی سیستم و درخواست وارد کردن تاریخ جدید (در صورت نیاز به رد شدن بدون تغییر، کافیست `Enter` بزنید).

### `time`
- نمایش ساعت دقیق سیستم و درخواست تنظیم ساعت جدید (با فشردن `Enter` بدون تغییر رد می‌شود).

## ۶. بررسی ویژگی فایل‌ها (`attrib`)

### `attrib`
- نمایش یا تغییر ویژگی‌ها (Attributes) مثل فقط‌خواندنی (Read-only)، مخفی (Hidden)، سیستمی (System) و آرشیو (Archive).
- حرف **`A`** مخفف **Archive** است و نشان می‌دهد فایل برای بکاپ آماده یا تغییر یافته است.

```cmd
D:\Test> attrib
A                    D:\Test\B.txt
```
*(اگر پوشه خالی باشد، پیام `File not found` می‌دهد).*
